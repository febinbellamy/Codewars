<h2><a href=https://www.codewars.com/kata/54f9173aa58bce9031001548/train/javascript target="_blank">The takeWhile Function</a></h2><h3>6 kyu</h3><p>Here's another staple for the functional programmer. You have a sequence of values and some predicate for those values. You want to get the longest prefix of elements such that the predicate is true for each element. We'll call this the <code>takeWhile</code> function. It accepts two arguments. The first is the sequence of values, and the second is the predicate function. The function does not change the value of the original sequence.</p><h3 id="example">Example:</h3><pre><code>sequence : [2,4,6,8,1,2,5,4,3,2]predicate: is an even numberresult   : [2,4,6,8]</code></pre><p>Your task is to implement the takeWhile function. </p><p>If you've got a <a href="http://www.codewars.com/kata/the-span-function" data-turbolinks="false" target="_blank">span function</a> lying around, this is a one-liner! Also, if you liked this problem, you'll surely love <a href="http://www.codewars.com/kata/the-dropwhile-function" data-turbolinks="false" target="_blank">the dropWhile function</a>.</p>
