<h2><a href=https://www.codewars.com/kata/57cbb9e240e3024aae000b26/train/javascript target="_blank">2 DNAs sequences, coding for same protein? </a></h2><h3>7 kyu</h3><p>In genetics, 2 different DNA sequences can code for the same protein. </p><p>This is due to the redundancy of the genetic code; in fact, 2 different tri-nucleotides can code for the same amino-acid.For example, the tri-nucleotide 'TTT' and the tri-nucleotide 'TTC' both code for the amino-acid 'F'. For more information you can take a look <a href="https://en.wikipedia.org/wiki/DNA_codon_table" data-turbolinks="false" target="_blank">here</a>.</p><p>Your goal in this kata is to determine whether two different DNA sequences code for exactly the same protein. Your function takes the 2 sequences you should compare.For the sake of simplicity, the sequences here will respect the following rules:</p><ul><li>It is a full protein sequence beginning with a Start codon and ending with a Stop codon</li><li>It will only contain valid tri-nucleotides.</li></ul><p>The translation hash is available for you under a translation hash <code>$codons</code> [Ruby] or <code>codons</code> [Python and JavaScript].</p><p>To better understand this kata, you can take a look at this <a href="https://www.codewars.com/kata/5708ef48fe2d018413000776" data-turbolinks="false" target="_blank">one</a>; it can help you to start. </p>
