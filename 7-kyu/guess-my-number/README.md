<h2><a href=https://www.codewars.com/kata/5654d2428be803670a000030/train/javascript target="_blank">Guess My Number</a></h2><h3>7 kyu</h3><p>Your goal is to create a function that takes a guess (string) and optionally a phone number (string).</p><p>Based on the guess, your function should display only the matching digits in the phone number, and hide the other digits with <code>#</code>:</p><pre><code class="language-javascript"><span class="cm-variable">guess</span> <span class="cm-operator">=</span> <span class="cm-string">"052"</span><span class="cm-variable">number</span> <span class="cm-operator">=</span> <span class="cm-string">"123-451-2345"</span><span class="cm-comment">// would return the string: "#2#-#5#-2##5"</span>    <span class="cm-variable">guess</span> <span class="cm-operator">=</span> <span class="cm-string">"142"</span><span class="cm-variable">number</span> <span class="cm-operator">=</span> <span class="cm-string">"123-451-2345"</span><span class="cm-comment">// would return the string: "12#-4#1-2#4#"</span></code></pre><p>The <code>guess</code> is a string of containing unordered and distinct digits (<code>0-9</code>).
