<h2><a href=https://www.codewars.com/kata/6a6bdaca77f722e42da8fba6/train/javascript target="_blank">Sensor Trend Reversals</a></h2><h3>7 kyu</h3><h1 id="sensor-trend-reversals">Sensor Trend Reversals</h1><p>A sensor records a sequence of integer readings.</p><p>Your task is to count how many times the trend changes between:</p><ul><li>increasing</li><li>decreasing</li></ul><p>A trend reversal occurs when an increasing sequence becomes decreasing, or when a decreasing sequence becomes increasing.</p><p>Consecutive equal readings do not create a direction and must be ignored.</p><h2 id="examples">Examples</h2><pre><code class="language-javascript"><span class="cm-variable">countDirectionChanges</span>([<span class="cm-number">1</span>, <span class="cm-number">3</span>, <span class="cm-number">2</span>, <span class="cm-number">4</span>]);<span class="cm-comment">// 2</span></code></pre><p>The directions are increasing, decreasing, then increasing, so the trend changes twice.</p><pre><code class="language-javascript"><span class="cm-variable">countDirectionChanges</span>([<span class="cm-number">5</span>, <span class="cm-number">3</span>, <span class="cm-number">1</span>]);<span class="cm-comment">// 0</span></code></pre><p>The readings are always decreasing.</p><pre><code class="language-javascript"><span class="cm-variable">countDirectionChanges</span>([<span class="cm-number">1</span>, <span class="cm-number">1</span>, <span class="cm-number">3</span>, <span class="cm-number">3</span>, <span class="cm-number">2</span>]);<span class="cm-comment">// 1</span></code></pre><p>Equal consecutive readings are ignored. The effective sequence is <code>[1, 3, 2]</code>.</p><pre><code class="language-javascript"><span class="cm-variable">countDirectionChanges</span>([<span class="cm-number">4</span>, <span class="cm-number">4</span>, <span class="cm-number">4</span>]);<span class="cm-comment">// 0</span></code></pre><p>There is no increasing or decreasing trend.</p><pre><code class="language-javascript"><span class="cm-variable">countDirectionChanges</span>([]);<span class="cm-comment">// 0</span></code></pre><h2 id="input">Input</h2><p><code>readings</code> is an array of integers.</p><h2 id="output">Output</h2><p>Return the number of times the trend changes direction.</p><h2 id="constraints">Constraints</h2><ul><li>The array may be empty.</li><li>Every element is an integer.</li><li>Consecutive equal values are ignored.</li><li>After consecutive duplicates are ignored, fewer than three readings produce <code>0</code>.</li></ul>
